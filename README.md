# BrickBreaker
🧱 Неоновый арканоид на чистом JavaScript. Разбивай кирпичи, ускоряйся, собирай очки. Красивое меню, частицы.

Классический арканоид в неоновом стиле. Разбивай кирпичи шариком, не дай ему упасть, прокачивай скорость.

## 🎮 Геймплей

- Управляй платформой мышкой или стрелками
- Шарик ускоряется каждые 5 секунд (до 3x)
- Проходи уровни — кирпичей всё больше, шарик всё быстрее
- Собирай очки, не теряй жизни

## ✨ Фичи

- 🎨 Неоновая графика с тенями и бликами
- 💥 Частицы при разбитии кирпичей
- ⚡ Автоускорение шарика
- 🖼️ Красивое стартовое меню
- ⏸ Пауза и Game Over с меню
- 📈 5+ уровней сложности
- 🏆 Счёт, жизни, уровень, скорость на экране

## 🕹 Управление

- **Мышь / Стрелки** — движение платформы
- **Пробел** — пауза
- **R** — рестарт

## 🚀 Запуск

Открой `index.html` в браузере. Никаких зависимостей.

- Чистый JavaScript
